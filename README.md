# 🎓 Online Course Management System

First Year B.Tech Java OOP Project

---

## 📁 Project Structure

```text
OnlineCourseManagementSystem/

│
├── Course.java
│     ← Course Information Management
│
├── Student.java
│     ← Student Enrollment & Progress Tracking
│
└── CourseSystem.java
      ← Main Program Execution
```

---

## 🚀 How to Run the Java Program

### Step 1 — Open Terminal

```bash
cd OnlineCourseManagementSystem
```

### Step 2 — Compile Java Files

```bash
javac *.java
```

### Step 3 — Run Main Class


---

## ✅ Java Concepts Demonstrated

| Concept | Where Used |
|----------|------------|
| Classes & Objects | Course, Student, CourseSystem |
| Encapsulation | Private Variables + Getters |
| Constructors | Course() and Student() |
| Arrays | Student[] and Course IDs |
| Method Calling | enroll(), addStudent() |
| Validation | updateProgress() |
| Loops | displayDetails() |
| Conditional Statements | Duplicate Enrollment Check |
| Object Interaction | Course ↔ Student |

```bash
java CourseSystem
```
